# Точка фокуса

Одностраничный React + TypeScript дашборд для целей, привычек, расписания, дневника и финансов.

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Production-проверка: `npm run build`.

## Приложение для Mac

Для запуска как отдельного приложения выполните `npm run app`.

Для создания установочного файла выполните `npm run dist:mac`. Готовые файлы появятся в папке `release`: откройте `.dmg`, перетащите «Мой трекер» в Applications и запустите его оттуда.

Если Electron-приложение блокируется системой, используйте установку через Safari: откройте production-сайт, нажмите `Файл` → `Добавить в Dock`. Дашборд установится как отдельное приложение macOS без Electron.

## Деплой

Подключите папку `goals-dashboard` к Netlify или Vercel. Команда сборки: `npm run build`, директория публикации: `dist`.

Все данные сохраняются в `localStorage` браузера. Кнопки в шапке позволяют экспортировать JSON и сбросить данные с подтверждением.
