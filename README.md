# Точка фокуса

Одностраничный React + TypeScript дашборд для целей, привычек, фиксированного недельного расписания, дневника и финансов.

## Рабочая версия

Production: https://goals-dashboard-uf6p.onrender.com

Расписание в трекере является **фиксированным шаблоном недели**: записи Пн–Вс не сдвигаются и не пересоздаются при переходе на следующую или предыдущую неделю. История привычек хранится отдельно по месяцам.

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Production-проверка:

```bash
npm run build
```

## Приложение для Mac

Для запуска как отдельного приложения выполните `npm run app`.

Для создания установочного файла выполните `npm run dist:mac`. Готовые файлы появятся в папке `release`: откройте `.dmg`, перетащите «Мой трекер» в Applications и запустите его оттуда.

Если Electron-приложение блокируется системой, используйте установку через Safari: откройте production-сайт, нажмите `Файл` → `Добавить в Dock`. Дашборд установится как отдельное приложение macOS без Electron.

## Деплой

Для Render используется `render.yaml`: сборка выполняется командой `npm install && npm run build`, запуск — `node server.js`.

Для Netlify или Vercel: команда сборки `npm run build`, директория публикации `dist`.

Все данные сохраняются в `localStorage` браузера. Кнопки в шапке позволяют экспортировать JSON и сбросить данные с подтверждением.
